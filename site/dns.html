Tampermonkey, aussi important que l’APK et l’EXE.

Notre script peut masquer certains résultats, publications et recommandations sur les pages Web compatibles. Il complète le blocage de domaines des applications, sans modifier les comptes ni supprimer les contenus.

L'extension doit être installée avant notre script. Disponibilité sur mobile variable selon le navigateur.

Applications de filtrage DNS et hosts

ANDROID • APK

VPN local réservé au DNS

Android doit autoriser un petit service VPN local qui détourne seulement les requêtes vers le serveur DNS virtuel de l'application. Les domaines sélectionnés renvoient une réponse « introuvable » ; les autres requêtes DNS sont transmises au résolveur externe configuré dans le code.

  • Pas de root, pas de serveur personnel.
  • Liste de domaines modifiable.
  • Activer et désactiver dans l'application.
  • Autorisation VPN à valider dans Android.

WINDOWS • EXE

Filtre de résolution locale des noms

Windows utilise ici le fichier système hosts : les noms de domaine inscrits sont redirigés vers une adresse locale non utilisable. Aucun service DNS permanent n'est nécessaire.

  • Validation administrateur Windows (UAC) avant modification.
  • Les modifications de l'outil sont isolées et réversibles.
  • Sauvegarde de sécurité de l'ancien fichier hosts.
  • Liste modifiable par l'utilisateur.

Installation en 4 étapes

Choisir votre version

Utilisez les boutons APK ou EXE sur cette page. Ils pointent toujours vers la dernière GitHub Release publiée avec succès.

Télécharger directement

Récupérez le fichier MonFilMesChoix_DNS.apk ou MonFilMesChoix_DNS.exe, sans ouvrir GitHub Actions ni extraire d’archive.

Installer sur votre appareil

Sur Android, ouvrez l'APK et autorisez l'installation depuis cette source. Sur Windows, exécutez le fichier .exe téléchargé et vérifiez sa provenance.

Activer et personnaliser

Par défaut, neuf domaines sont proposés. Modifiez-les si besoin, puis activez. En cas de gêne, utilisez « Désactiver ».

Ce qui est filtré

Un domaine sert d'exemple de blocage technique, pas de jugement sur les personnes qui travaillent pour le site. Les deux applications utilisent cette même liste initiale, éditable individuellement.

Exporter les 9 domaines (JSON)

Limites à connaître

  • Android : seule la résolution DNS classique IPv4/UDP passant par le VPN local est traitée dans cette première version. Le DNS privé, DoH, le DNS TCP, un autre VPN ou certaines applications peuvent contourner le filtrage.
  • Windows : hosts bloque les noms exacts et leurs variantes www., pas les autres sous-domaines. Certains logiciels ou réseaux peuvent contourner ce mécanisme.
  • Les boutons directs deviennent actifs après la première publication GitHub Release réussie. Les exécutables ne sont pas signés commercialement. En attendant, consultez la page Releases.
  • Aucune suppression sur les plateformes et aucun blocage de comptes Facebook à distance.

Besoin d’aide avec une IA ?

Notre guide rassemble des demandes prêtes à copier pour vérifier une page, préparer uniquement les domaines confirmés et résoudre les problèmes d’installation. L’IA ne peut pas bloquer à elle seule tous les noms sur tous les sites.

Pourquoi cette liste ?

Le but est de donner aux internautes des outils concrets pour gérer leur exposition aux sources, opinions et contenus qu'ils ne souhaitent plus voir. La sélection est personnelle : chacun peut supprimer une entrée, en ajouter une ou désactiver entièrement le filtre. La présence d'un nom dans l'annuaire n'implique pas automatiquement une conduite illégale. La base documentaire et la sélection de domaines ont des usages différents.

Le code source du filtre est public et ne contient aucun module de collecte d'identifiants ou de surveillance de comptes. Le serveur DNS utilisé par la version Android reste un service externe qui peut, comme tout résolveur DNS, observer les noms interrogés.
