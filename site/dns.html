01 · FILTRE POUR NAVIGATEUR

Tampermonkey, aussi important que l’APK et l’EXE.

Notre script peut masquer certains résultats, publications, recommandations et emplacements publicitaires sur les pages Web compatibles (publicités : option facultative). Il complète le blocage de domaines des applications, sans modifier les comptes ni supprimer les contenus.

L'extension doit être installée avant notre script. Disponibilité sur mobile variable selon le navigateur.

MODE INVISIBILITÉ · V27 · FACULTATIF

Mode invisibilité : faire disparaître les contenus qui mentionnent un nom

Vous pouvez choisir vos propres mots ou expressions à masquer. Exemple : « Le Pen ». Le module tente de cacher les cartes de résultats et publications qui contiennent cette expression, quelle que soit l'orientation du média, sur les sites compatibles.

Installation : installez l'extension Tampermonkey dans votre navigateur, puis ajoutez ce deuxième script facultatif. Ouvrez ensuite le menu Tampermonkey → « Mes mots-clés invisibles », saisissez une expression par ligne et actualisez la page. Aucune expression n'est imposée au départ.

Installer le module « Invisibilité » Comprendre Tampermonkey

Important : ce n'est ni une fonction de l'EXE Windows, ni une fonction DNS de l'APK. Il s'agit d'un filtre du navigateur. Il peut masquer une carte qui cite simplement une expression, mais ne garantit pas le masquage de toutes les vidéos, publications ou pages. Vous pouvez le désactiver, tout réafficher sur un onglet ou préserver certains sites grâce aux exceptions. Les réglages restent locaux.

Masquage discret : les blocs reconnus disparaissent sans message ni espace réservé, mais le résultat dépend de la structure de chaque site. Une simple mention peut masquer une publication utile. Les autres applications Android et Windows ne sont pas filtrées par ce module.

Applications de filtrage DNS et hosts

ANDROID • APK

VPN local réservé au DNS

Android doit autoriser un petit service VPN local qui détourne seulement les requêtes vers le serveur DNS virtuel de l'application. Les domaines sélectionnés renvoient une réponse « introuvable » ; les autres requêtes DNS sont transmises au résolveur externe configuré dans le code.

  • Pas de root, pas de serveur personnel.
  • Liste de domaines modifiable.
  • Activer et désactiver dans l'application.
  • Autorisation VPN à valider dans Android.

Windows affiche une page bleue ? Comprendre SmartScreen

Mon fil, mes choix est un outil indépendant, gratuit et à code source public. Ce n'est pas une application Microsoft ni un produit officiellement approuvé par Microsoft. L'EXE téléchargé depuis GitHub n'est pas signé numériquement par un éditeur reconnu ; Windows Defender SmartScreen peut donc le présenter comme une « application non reconnue », notamment lorsqu'il a encore peu de réputation.

Cela ne signifie pas automatiquement que le logiciel contient un virus. À l'inverse, un avertissement SmartScreen ne doit jamais être ignoré sans vérification : une détection explicite de malware par un antivirus doit être prise au sérieux.

Vérifications avant d'utiliser l'EXE

  1. Téléchargez le fichier uniquement depuis la Release officielle du dépôt de ce projet, jamais depuis une copie envoyée par un inconnu.
  2. Dans la même Release, récupérez SHA256SUMS.txt. Sur Windows, vous pouvez calculer l'empreinte du fichier avec certutil -hashfile MonFilMesChoix_DNS.exe SHA256 et comparer le résultat à la valeur publiée. Une empreinte identique confirme le fichier téléchargé, pas son innocuité absolue.
  3. Si l'alerte est uniquement « Windows a protégé votre ordinateur / application non reconnue », le lien « Informations complémentaires » indique le fichier et l'éditeur avant toute décision. Ne poursuivez que si vous avez vérifié sa provenance et acceptez le risque résiduel.
  4. Si Windows signale un virus, un cheval de Troie ou met le fichier en quarantaine, ne forcez pas son exécution. Faites-nous parvenir le nom exact de la détection pour enquête.

Inutile de désactiver Microsoft Defender ou votre antivirus. Le logiciel Windows demande des droits administrateur uniquement lors de la modification du fichier hosts ; ce changement est réversible dans l'application.

Un logiciel gratuit et indépendant peut tout à fait être signé à l'avenir. L'absence actuelle de signature n'est pas une preuve de sécurité ou d'insécurité.

Utilisez les boutons APK ou EXE sur cette page. Ils pointent toujours vers la dernière GitHub Release publiée avec succès.

Récupérez le fichier MonFilMesChoix_DNS.apk ou MonFilMesChoix_DNS.exe, sans ouvrir GitHub Actions ni extraire d’archive.

Installer sur votre appareil

Sur Android, ouvrez l'APK et autorisez l'installation depuis cette source. Sur Windows, exécutez le fichier .exe téléchargé et vérifiez sa provenance.

Activer et personnaliser

Les 303 entrées sont sélectionnées par défaut, avec neuf domaines techniques identifiés initialement. Modifiez-les si besoin, puis activez. En cas de gêne, utilisez « Désactiver ».

Ce qui est filtré

Un domaine sert d'exemple de blocage technique, pas de jugement sur les personnes qui travaillent pour le site. Les deux applications utilisent cette même liste initiale, éditable individuellement.

Limites à connaître

  • Android : seule la résolution DNS classique IPv4/UDP passant par le VPN local est traitée dans cette première version. Le DNS privé, DoH, le DNS TCP, un autre VPN ou certaines applications peuvent contourner le filtrage.
  • Windows : hosts bloque les noms exacts et leurs variantes www., pas les autres sous-domaines. Certains logiciels ou réseaux peuvent contourner ce mécanisme.
  • Les boutons directs deviennent actifs après la première publication GitHub Release réussie. Les exécutables ne sont pas signés commercialement. En attendant, consultez la page Releases.
  • Aucune suppression sur les plateformes et aucun blocage de comptes Facebook à distance.

Pourquoi cette liste ?

Le but est de donner aux internautes des outils concrets pour gérer leur exposition aux sources, opinions et contenus qu'ils ne souhaitent plus voir. La sélection est personnelle : chacun peut supprimer une entrée, en ajouter une ou désactiver entièrement le filtre. La présence d'un nom dans l'annuaire n'implique pas automatiquement une conduite illégale. La base documentaire et la sélection de domaines ont des usages différents.

Le code source du filtre est public et ne contient aucun module de collecte d'identifiants ou de surveillance de comptes. Le serveur DNS utilisé par la version Android reste un service externe qui peut, comme tout résolveur DNS, observer les noms interrogés.

Publicités et blocages personnalisés

La V15 ajoute une section facultative dans les applications Android et Windows : téléchargez manuellement une liste de domaines, puis activez ou désactivez chaque source, et ajoutez vos domaines personnels.

  • Sources : AdAway et StevenBlack.
  • Le téléchargement n’est jamais automatique : vous donnez votre accord. Les fichiers sont conservés localement.
  • Pour éviter de surcharger le filtrage, chaque source est limitée à 10 000 domaines. C’est donc une protection partielle, pas l’intégralité de toutes les sources.
  • Vous pouvez bloquer un domaine comme ads.exemple.fr, mais pas des mots, des images ou un profil isolé dans Facebook.
  • Si un site utile cesse de fonctionner, désactivez temporairement la liste concernée.
