Installer Tampermonkey pas à pas.

Ce guide a été pensé pour les personnes qui ne connaissent pas encore les scripts utilisateur. Vous y trouverez les étapes dans le bon ordre, des captures d’écran illustratives et des solutions si quelque chose ne fonctionne pas.

Résumé en 5 étapes

Suivez toujours cet ordre. Si une étape ne marche pas, passez à la partie dépannage plus bas.

  1. Installer l’extension Tampermonkey dans le navigateur.
  2. Autoriser les scripts utilisateur si le navigateur le demande.
  3. Ouvrir et installer le script « Mon fil, mes choix ».
  4. Tester le menu Tampermonkey sur une page Web.
  5. Choisir les groupes à masquer dans « Gérer les groupes ».

Ce qu’il vous faut

Un navigateur compatible avec Tampermonkey sur ordinateur. Sur téléphone, la compatibilité dépend du navigateur utilisé.

À quoi sert le script

Le script masque localement des résultats, cartes ou publications sur certains sites compatibles. Il ne supprime rien à la source.

Important

Si un site change de structure, il peut falloir mettre le script à jour. Vous pouvez aussi désactiver le filtre à tout moment.

Guide spécial téléphone

Installer le script en copiant le code sur Samsung

Ce parcours est prévu si Tampermonkey affiche encore « New Userscript » sur votre téléphone. Les visuels sont des illustrations annotées, inspirées de l'interface mobile : les boutons exacts peuvent varier selon votre navigateur et sa version.

Voir le guide d'installation classique
01

Ouvrez « New Userscript » → « Éditer »

Dans Tampermonkey, touchez la ligne « Éditer » sous le script créé par défaut.

02

Effacez le code présent

Dans l'éditeur, sélectionnez tout le code par défaut puis supprimez-le. N'en gardez aucune ligne.

03

Collez le véritable script puis enregistrez

Revenez sur notre site, utilisez « Copier le script », puis collez son contenu dans l'éditeur Tampermonkey et utilisez l'icône de sauvegarde. Ne recopiez pas le faux code présent dans l'illustration.

04

Vérifiez le nouveau nom

Le script doit s'appeler « Mon fil, mes choix — filtre Web personnel » et être activé. Revenez sur Google, rechargez la page et ouvrez « Gérer les groupes (9) ».

Le guide détaillé

Chaque étape ci-dessous montre ce que vous devez faire et ce que vous devriez voir à l’écran. Les captures sont illustratives, pour vous aider à vous repérer plus facilement.

01

Installer l’extension officielle

Commencez toujours par l’extension officielle Tampermonkey. Sans elle, le script ne pourra pas s’installer ni fonctionner.

  • Ouvrez le site officiel tampermonkey.net.
  • Choisissez votre navigateur (Chrome, Edge, Firefox ou un autre navigateur compatible).
  • Validez l’installation si le navigateur affiche une fenêtre de confirmation.
02

Autoriser les scripts utilisateur

Certains navigateurs demandent une autorisation supplémentaire pour que les scripts utilisateur fonctionnent correctement.

  • Ouvrez la gestion de l’extension Tampermonkey.
  • Cherchez l’option « Autoriser les scripts utilisateur ».
  • Activez-la si elle est visible. Sur certains navigateurs, activez aussi le mode développeur.
03

Installer le script Mon fil, mes choix

Une fois l’extension prête, ouvrez notre script. Tampermonkey affichera normalement une page d’installation. Sur téléphone, si vous voyez « New Userscript » comme sur votre capture, utilisez plutôt le bouton de copie ci-dessous.

Appuyez pour copier le code complet. Il ne faut pas copier seulement le lien.

Si la copie automatique est bloquée : sélectionnez le texte ci-dessous et choisissez « Copier » dans le menu du téléphone.

Sur votre téléphone Samsung :
  1. Dans Tampermonkey, appuyez sur « New Userscript » → « Éditer ».
  2. Dans l’éditeur, sélectionnez tout le code par défaut et supprimez-le.
  3. Faites un appui long, puis « Coller » le script complet copié.
  4. Enregistrez dans l’éditeur Tampermonkey, puis rechargez Google.
  5. Le script doit s’appeler « Mon fil, mes choix — filtre Web personnel », pas « New Userscript ».
  • Cliquez sur ce lien : installer notre script.
  • Vérifiez que le nom du script affiché contient bien « Mon fil, mes choix ».
  • Appuyez sur « Installer ».
  • Si rien ne se passe, ouvrez le tableau de bord Tampermonkey, créez un script, collez le contenu du fichier, puis enregistrez.
04

Tester le menu et choisir un mode

Après installation, ouvrez une page Web puis le menu Tampermonkey. Le script doit apparaître comme activé.

  • Repérez le script « Mon fil, mes choix » dans le menu.
  • Essayez les modes proposés : liste complète, blocages demandés seulement, afficher tout, désactiver.
  • Rechargez la page Web si vous venez tout juste d’installer ou de modifier le script.
05

Choisir les groupes que vous voulez masquer

La V12 contient les 303 entrées de la liste, réparties en 9 groupes indépendants. Tous les groupes sont actifs lors de la première installation.

  • Ouvrez le menu de l’extension Tampermonkey sur une page Web ordinaire, par exemple une recherche Google.
  • Choisissez « ⚙️ Gérer les groupes (9) » dans le menu du script.
  • Cochez ou décochez les groupes souhaités. Le changement est immédiatement enregistré.
  • Utilisez « Tout activer » ou « Tout désactiver » si vous préférez commencer de zéro.
  • Fermez le panneau, puis rechargez la page si des résultats restent visibles.

Exemple : si vous désactivez le groupe « Médias et groupes de presse », CNews ne sera plus masqué par notre script. Pour le masquer, réactivez ce groupe.

Tout fonctionne si…

  • L’extension Tampermonkey est visible dans le navigateur.
  • Le script « Mon fil, mes choix » apparaît dans son tableau de bord.
  • Le menu du script s’ouvre sur une page Web.
  • Le rechargement de la page active le masquage local.

À retenir

  • Le filtrage est local : il ne change rien sur les sites eux-mêmes.
  • Tous les sites ne sont pas compatibles de la même façon.
  • Certains mots trop courts ou trop génériques ne sont pas bloqués pour éviter les erreurs.
  • Vous pouvez désactiver le script quand vous voulez.
Attention : un script Tampermonkey peut parfois provoquer des faux positifs. Si une page masque trop de choses, utilisez « Afficher tout sur cette page » ou désactivez temporairement le script pour vérifier.

Dépannage rapide

Je clique sur le script, mais rien ne s’installe.

Vérifiez d’abord que l’extension Tampermonkey est bien installée. Ensuite, retournez sur le lien du script. Si le navigateur l’ouvre comme un simple texte, copiez le contenu dans « Tableau de bord → Créer un script », puis enregistrez.

Je ne trouve pas l’option « Autoriser les scripts utilisateur ».

Selon le navigateur, cette option peut ne pas être visible. Si elle n’apparaît pas, vérifiez le mode développeur ou consultez la documentation officielle de Tampermonkey pour votre navigateur.

Le script est installé, mais rien ne change sur la page.

Rechargez la page Web. Ouvrez ensuite le menu Tampermonkey pour vérifier que le script est activé sur cette page. Certains sites peuvent aussi être moins compatibles que d’autres.

Je veux revenir en arrière.

Vous pouvez désactiver le script depuis le menu Tampermonkey, ou le supprimer complètement depuis le tableau de bord de l’extension.
