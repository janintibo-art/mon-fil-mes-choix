Guide pratique • Assistance par intelligence artificielle

Utiliser l’IA pour reprendre la main sur son fil.

Une IA peut aider à identifier des pages publiques, vérifier une affiliation, préparer une liste de domaines et expliquer les manipulations. Elle ne peut pas garantir le blocage universel de 303 noms sur tous les sites, ni agir sur votre compte sans votre autorisation et les outils adaptés.

Une méthode en trois étapes

01

Choisir ce que l’on souhaite masquer

Parcourez l’annuaire, recherchez un nom, et distinguez une demande de blocage d’un compte encore « à examiner ». Les 303 entrées ne sont pas 303 domaines DNS.

02

Demander une vérification à l’IA

Faites confirmer l’URL officielle, la date et les sources. Refusez les rapprochements sur la base d’un simple nom, d’une ancienne collaboration ou d’une rumeur.

03

Choisir l’outil adapté

Filtre Tampermonkey pour les contenus visibles dans le navigateur, APK pour une partie des requêtes DNS Android, EXE Windows pour le fichier hosts. Conservez toujours un moyen de désactiver.

Comprendre les trois outils

NAVIGATEUR

Tampermonkey

Filtre du texte visible dans certaines cartes, vidéos ou résultats. Peut masquer un site selon son domaine depuis le navigateur, mais ne bloque pas les comptes côté serveur.

  • Installer l’extension dans un navigateur compatible.
  • Installer le script depuis le site.
  • Commencer par le mode « demandes confirmées ».
  • Afficher une fois ou désactiver si le résultat est trop large.
Tutoriel Tampermonkey
ANDROID • APK EXPÉRIMENTALE

DNS local

Le prototype emploie un VPN local pour traiter certaines requêtes DNS classiques. Il ne filtre pas les vidéos ou profils internes d’une plateforme.

  • Autoriser le service VPN dans Android.
  • Modifier les domaines si nécessaire.
  • Ne fonctionne pas forcément avec un autre VPN ou le DNS chiffré.
  • Désactiver le VPN local si le réseau fonctionne mal.
Guide Android
WINDOWS • EXE EXPÉRIMENTAL

Fichier hosts

L’application ajoute les domaines approuvés au fichier hosts après consentement administrateur. Elle ne change pas les serveurs DNS système.

  • Vérifier la provenance de l’EXE.
  • Choisir les domaines et activer.
  • Accepter la demande UAC seulement si vous le souhaitez.
  • Désactiver pour retirer les règles du programme.
Guide Windows
Important : aucune IA ne peut garantir « tout bloquer partout ». Les comptes, les images, les homonymes, les sites miroirs et les contenus chargés dynamiquement demandent des méthodes différentes. Les filtres sont locaux et réversibles. Les applications Android/Windows restent à compiler et à tester sur les appareils réels.

Confidentialité, exactitude et contrôle

Ne communiquez jamais votre mot de passe, votre cookie de session ni vos codes de double authentification à une IA. Pour une intervention sur le navigateur ou le PC, utilisez uniquement les outils de contrôle explicitement autorisés par vous. L’IA peut préparer une liste ou un script, mais ce n’est pas une preuve qu’un compte est réellement bloqué.

Le répertoire est une sélection personnelle de contenus à masquer. Une présence dans la liste n’établit ni une infraction ni l’adhésion à toutes les opinions d’un mouvement. Les relations anciennes et les homonymies doivent être signalées ; une affiliation incertaine reste à vérifier avant tout ajout.

Pour consulter et exporter les données : répertoire complet, CSV des 303 entrées, JSON des neuf domaines initiaux. Documentation : Tampermonkey, Android VpnService, GitHub Pages.
